# PasswordEntryRow

libadwaita: [`PasswordEntryRow`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.PasswordEntryRow.html)

## What it is

An EntryRow for secrets: hidden text, no clipboard copy, Caps Lock warning, reveal toggle.

## CSS nodes and classes

`row.entry.password`.

## iced mapping

`password_entry_row(title, value)` hides the text. Reveal toggle and Caps Lock warning not implemented.
