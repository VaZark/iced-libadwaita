# StackSwitcher

GTK4: [`GtkStackSwitcher`](https://docs.gtk.org/gtk4/class.StackSwitcher.html)

## What it is

Row of buttons controlling a `GtkStack`.

## CSS nodes

```
stackswitcher.stack-switcher
```

## Style classes and states

`.stack-switcher`, `.needs-attention` on page widgets.

## Adwaita defers

Use `AdwViewSwitcher` / `AdwInlineViewSwitcher` / `AdwToggleGroup`.

## iced mapping

`view_switcher`, `inline_view_switcher`, `toggle_group`.
