# SearchEntry

GTK4: [`GtkSearchEntry`](https://docs.gtk.org/gtk4/class.SearchEntry.html)

## What it is

Entry for search: inactive _find_ icon when empty, _clear_ icon when it has text; `search-changed` is emitted after a delay; key capture from another widget.

## CSS nodes

```
entry.search
╰── text
```

## Style classes and states

`.search`

_Not implemented; use `text_input` with the default style._
