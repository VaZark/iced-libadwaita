# Using the library

How, when and what to use to build a good GNOME app. Guidance for people and agents; for the API
see the rustdoc, and for why things look the way they do see [`../hig-inferences/`](../hig-inferences/README.md).

- [choosing.md](choosing.md): which component for which job.
- [layout.md](layout.md): pages, rows, adaptive layouts and the sidebar.
- [windows-and-menus.md](windows-and-menus.md): decorations, header bars, menus, toasts.
- [theming.md](theming.md): colors, contrast, radii, shadows, density.
- [motion.md](motion.md): animation and reduced motion.
- [components.md](components.md): the shape every component has; [catalog](components-catalog.md)
  lists every tag.
- [desktop-config.md](desktop-config.md): the shared desktop config; [sample](desktop.conf.example).
- [config-registry.md](config-registry.md): the versioned registry behind it: types, defaults,
  `since`, deprecation, and what apps ignore.
