# CarouselIndicatorDots and CarouselIndicatorLines

libadwaita: [`CarouselIndicatorDots`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.CarouselIndicatorDots.html)

## What it is

Page indicators bound to a carousel. Dots: active dot larger/more opaque, animated with the carousel position. Lines: one line per page with a moving active line.

## CSS nodes and classes

Nodes `carouselindicatordots`, `carouselindicatorlines`.

## Spec

Sizes not documented.

## iced mapping

`carousel_indicator_dots/lines(count, index, on_navigate)`.
