# ShortcutsDialog

libadwaita: [`ShortcutsDialog`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.ShortcutsDialog.html)

## What it is

Lists keyboard shortcuts in sections of items (title, accelerator, action, direction) (1.8).

## Anatomy and behavior

Sections without titles subdivide groups.

## iced mapping

`shortcuts_dialog(sections, on_close)`.

## Deviations / gaps

No search.
