# Switch (GtkSwitch)

libadwaita: [`SwitchRow`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.SwitchRow.html)

## What it is

Not an Adw class; documented because SwitchRow and ExpanderRow embed it.

## Anatomy and behavior

Track accent when on, translucent when off, circular knob that slides; drag or click.

## Spec

≈46×26 track, 20px knob ‡.

## iced mapping

`adw::widget::Switch` (custom widget) with these proportions; `style::toggler` remains for stock iced `toggler`.
