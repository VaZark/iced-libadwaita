# AboutDialog

## What it is

Application information: icon, name, developer, version badge, links, What's New, Details, Troubleshooting, Credits, Acknowledgements, Legal (1.5).

## Anatomy and behavior

Every part optional; extra links, credit sections, legal sections.

## CSS nodes and classes

`dialog.about`.

## iced mapping
