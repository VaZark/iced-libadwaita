# NavigationPage

libadwaita: [`NavigationPage`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.NavigationPage.html)

## What it is

A page (child, title, optional tag) in a NavigationView/SplitView.

## Anatomy and behavior

Signals `showing`/`shown`/`hiding`/`hidden`; `can-pop`.

## CSS nodes and classes

`navigation-view-page`.

## iced mapping

`NavigationPage::new(title, content)`.
