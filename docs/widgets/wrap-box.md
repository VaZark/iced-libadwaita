# WrapBox

libadwaita: [`WrapBox`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.WrapBox.html)

## What it is

Box that wraps children onto new lines like words (1.7).

## Anatomy and behavior

`child-spacing`, `line-spacing`, `natural-line-length`, `wrap-policy`, `justify`, `align`, `pack-direction`, `wrap-reverse`, `line-homogeneous`.

## CSS nodes and classes

`wrap-box`.

## Spec

Example spacing 6 / 6.

## iced mapping

`wrap_box(children, spacing)` (iced `Row::wrap`).

## Deviations / gaps

No justify/align options.
