# Clamp

libadwaita: [`Clamp`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.Clamp.html)

## What it is

Constrains the child to a maximum size but lets it shrink; eases from min to max; `tightening-threshold`, `unit`.

## CSS nodes and classes

`clamp`.

## Spec

Preferences pages: max 600.

## iced mapping

`clamp(content, max)` (center-x, max-width, fill below it).
