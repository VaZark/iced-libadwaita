# WindowTitle

libadwaita: [`WindowTitle`](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.WindowTitle.html)

## What it is

Title + subtitle helper for header bars.

## CSS nodes and classes

`windowtitle`.

## Spec

Title is `.heading`, subtitle `.caption` dimmed, centered.

## iced mapping

`window_title(title, subtitle)`.
