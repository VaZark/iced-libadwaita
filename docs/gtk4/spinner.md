# Spinner

GTK4: [`GtkSpinner`](https://docs.gtk.org/gtk4/class.Spinner.html)

## What it is

Icon-size spinning animation for indefinite activity; `start`/`stop`; `:checked` while spinning.

## CSS nodes

```
spinner
```

## Style classes and states

None.

## Adwaita defers

`AdwSpinner` (1.6) is the Adwaita widget, sized 16–64px and used by `AdwStatusPage`.

## iced mapping

`adw::widget::spinner`.
